---
title: "Markdown"
description: "Format ticket descriptions and replies."
---

Use the toolbar, or type Markdown. Select **Preview** to check it.

| Type | To get |
| --- | --- |
| `**bold**` | Bold |
| `*italic*` | Italic |
| `` `code` `` | Code |
| `[text](https://example.com)` | A link |
| `- item` | A bulleted list |
| `1. item` | A numbered list |
| `> quote` | A quote |
| Three backticks on the lines before and after | A code block |
