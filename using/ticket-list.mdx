## Tiles

Select **Open** or **Assigned to me** to show those tickets. Select it again to turn it off.

## Search

Search by title, number, or requester.

## Filters

Select **Filters** to filter by status, assignment, client, category, or SLA. Filters in use appear as chips. Select a chip to remove it.

## Sort

| Sort | Shows first |
| --- | --- |
| Recent activity first | The latest activity. |
| SLA due soonest | The nearest deadline. |
