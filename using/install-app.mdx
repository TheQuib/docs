---
title: "Install the app"
description: "Install desk on your phone or computer, and turn on notifications."
---

<Info>
  **Who:** Everyone  
  **Where:** Settings → Account → App and notifications
</Info>

## Install

<Tabs>
  <Tab title="Chrome and Edge">
    Select **Install app** in **Settings → Account**.
  </Tab>
  <Tab title="iPhone and iPad">
    Select **Share**, then **Add to Home Screen**. Open desk from the new icon. Notifications only work from this icon.
  </Tab>
  <Tab title="Other browsers">
    Look in the browser’s menu. Firefox on a computer can’t install apps.
  </Tab>
</Tabs>

## Turn on notifications

<Steps>
  <Step title="Turn on Push notifications on this device">
    Allow the browser’s prompt.
  </Step>
  <Step title="Select Send a test">
    A notification arrives on this device.
  </Step>
</Steps>

Do this on each device. You still receive email.
