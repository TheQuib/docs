# desk docs

Public docs for desk, mostly for admins of a client's help desk. The app's code is in the private `desk` repo, at `C:\Repos\desk`. Check facts against it, and never copy its internals here.

## Writing

- Say what something does, what happened, or what to do next. Use as few words as possible.
- Write for someone doing the task. Keep steps, tables and troubleshooting. Cut history and reasoning.
- Don't name hosting, databases, deployment, migrations or environment variables. When an admin can't fix something, write "Contact whoever set up this help desk."
- Use American spellings.
- Use one word for one thing everywhere: "off", not "disabled". Match the app's labels exactly.
- Use sentence case for headings.
