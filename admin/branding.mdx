{/* Screenshot: Settings → Branding, preview and form */}

The preview updates as you type. It shows the app and sign-in screen, in light and dark.

| Setting | What it does |
| --- | --- |
| Organization name | Replaces the default name. |
| Accent color | A hex color, such as #0f5f73. The shade adjusts to stay readable. |
| Logo URL | Your logo. Emails always use this one. |
| Dark mode logo URL | Your logo in dark mode. Leave blank to use the logo above. |
| Favicon URL | The icon in the browser tab. A square PNG, SVG, or ICO works best. |
| Tab title | The name in the browser tab. Leave blank to use the organization name. |
| Public site URL | Your help desk’s address, used in emails. |

## Troubleshooting

<AccordionGroup>
  <Accordion title="My logo doesn’t load">
    The field shows why. Check that the URL opens the image.
  </Accordion>
  <Accordion title="My color looks different in dark mode">
    The shade adjusts to stay readable. The field says when it does.
  </Accordion>
</AccordionGroup>
