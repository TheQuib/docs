---
title: "Categories"
description: "Add, reorder, and delete ticket categories."
---

<Info>
  **Who:** Admins  
  **Where:** Settings → Tickets → Categories
</Info>

{/* Screenshot: Settings → Tickets, Categories */}

Category changes save immediately.

| To | Do this |
| --- | --- |
| Add a category | Enter a name and optional description, then select **Add category**. |
| Change a category | Select **Edit**. |
| Hide a category | Turn off **Shown**. |
| Reorder categories | Drag them, or use the arrow keys. |
| Delete a category | Select **Delete**. Existing tickets keep it. |

At least one category must be shown.
