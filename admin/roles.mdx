| Internal notes | ✓ | ✓ | — |
| Assign, set status and priority | ✓ | ✓ | — |
| Add clients | ✓ | ✓ | — |
| Add staff and admins | ✓ | — | — |
| Change admin settings | ✓ | — | — |

Admin settings: Branding, Tickets, SLAs, Client management, Locations, Notifications, and Email activity.

## All client tickets

Lets a client see and reply on all tickets for their client. Admins turn this on for each person. See [Manage access](/admin/people/manage-access).
