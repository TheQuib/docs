<Info>
  **Who:** Admins  
  **Where:** Settings → Locations
</Info>

{/* Screenshot: Settings → Locations */}

| Setting | What it does |
| --- | --- |
| Name | The name shown to staff. Required, and must be unique. |
| Client | The client it belongs to. Choose **Shared** for a location with no single owner. |
| Phone | Optional. |
| Address | Street address, Address line 2, City, State or region, Postal code, and Country. |
| Notes | Access instructions, parking, and on-site contacts. |
| Shown | Hidden locations stay on existing tickets but aren’t offered for new ones. |

People without a client can only be assigned to shared locations.
