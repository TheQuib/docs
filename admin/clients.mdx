<Info>
  **Who:** Admins  
  **Where:** Settings → Client management
</Info>

{/* Screenshot: Settings → Client management */}

| Setting | What it does |
| --- | --- |
| Name | The organization’s name. Required. |
| Email domains | One per line. Assigns new accounts and emailed tickets from that domain to this client. |
| Notes | Anything staff should know when working their tickets. |

Each domain can belong to only one client. Staff and admin accounts are never assigned by domain.

## Assign existing accounts

When accounts at a new domain have no client, the form offers **Assign**. Select it to add them to this client.
