## Email

<AccordionGroup>
  <Accordion title="Someone receives too many emails">
    Change the rows in [Who gets notified](/admin/notifications/who-gets-notified).
  </Accordion>
  <Accordion title="Someone receives no email">
    Check [Who gets notified](/admin/notifications/who-gets-notified), then [Email activity](/admin/notifications/email-activity).
  </Accordion>
  <Accordion title="SLA reminders arrive all at once">
    Contact whoever set up this help desk.
  </Accordion>
</AccordionGroup>

## Push

<AccordionGroup>
  <Accordion title="Account says push is off for the help desk">
    Turn on **Send push notifications**, then select **Save**.
  </Accordion>
  <Accordion title="iPhone or iPad asks to add to the Home Screen">
    Open desk from its Home Screen icon. See [Install the app](/using/install-app).
  </Accordion>
  <Accordion title="Notifications are blocked for the site">
    Allow them in the browser’s site settings.
  </Accordion>
  <Accordion title="The test says sent, but nothing arrives">
    Check Focus modes and Do Not Disturb. On a computer, check that notifications are allowed for the browser.
  </Accordion>
  <Accordion title="Push stopped on one device">
    Turn on **Push notifications on this device** again in **Settings → Account**.
  </Accordion>
  <Accordion title="Nothing arrives on any device">
    Contact whoever set up this help desk.
  </Accordion>
</AccordionGroup>
